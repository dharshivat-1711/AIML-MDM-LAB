# ASS-6: Clustering

## Assignment
Implement clustering algorithms on a real-world dataset and evaluate cluster quality.

## Dataset
Kaggle Mall Customer Segmentation Dataset:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

The notebook downloads and extracts `Mall_Customers.csv` automatically. It uses Annual Income (k$) and Spending Score (1-100).

## Algorithms
- K-Means (k=5; Elbow Method used to inspect k)
- Agglomerative Clustering (Ward linkage, 5 clusters)
- DBSCAN (eps=0.35, min_samples=5)

## Evaluation
Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Score, cluster plots, dendrogram, and cluster profiles.
