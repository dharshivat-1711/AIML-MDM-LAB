# ASS-3 - Regression Models and Gradient Descent

## Practical
1. Develop Regression Models for any real-world application and evaluate the performance using appropriate metrics.
2. Implement and analyze the performance of Gradient Descent optimization for Linear Regression.

## Dataset
Diabetes dataset from Scikit-learn (`load_diabetes`).

- Samples: 442
- Features: 10
- Target: Continuous
- Train-test split: 80:20
- Random state: 42

## Models
- Linear Regression
- Ridge Regression
- Polynomial Regression (Degree 2)
- Gradient Descent Linear Regression

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Gradient Descent
- Learning rate: 0.03
- Epochs: 5000
- StandardScaler used before training
- MSE loss history recorded for convergence analysis
